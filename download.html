Install it

  1. Tap Download APK, then open the file from your notifications or the Files app.
  2. If Android says your browser isn't allowed to install apps, tap Settings, turn on Allow from this source, then go back.
  3. Tap Install, then Open.

Google Play Protect may say the app is from an unknown developer. That's because this copy doesn't come from Play. Tap More details › Install anyway. Only download ScottPrivacy from this page.

Updates

ScottPrivacy checks this website once a day. When there's a new version it asks you, downloads it, checks it, and Android asks you to confirm the update. The first time, Android asks you to allow ScottPrivacy to install unknown apps; that's only used for its own updates.

You can also check any time: Settings › Check for updates.

Also on Palm Store

On Tecno, Infinix and itel phones you can also install ScottPrivacy from Palm Store, which keeps it updated for you. A copy from Palm Store and one from this page can't update each other: to switch, uninstall the old one first.
