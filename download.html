Install it in 3 steps

  1. Open the file. When the download finishes, tap it in your notifications or open it from the Files app.
  2. Allow this once. If Android says your browser can't install apps, tap Settings, turn on Allow from this source, then go back.
  3. Install and open. Tap Install, then Open. ScottPrivacy walks you through the rest.

Google Play Protect may say the app is from an unknown developer, because this copy doesn't come from Google Play. Tap More details › Install anyway. Only download ScottPrivacy from this website.

Updates install themselves

Once a day the app checks this website. When there's a new version it asks you, downloads it, checks it, and Android asks you to confirm. You can also tap Settings › Check for updates.
