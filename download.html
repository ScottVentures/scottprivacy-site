Install it in 3 steps

  1. Open the file. When the download finishes, tap it in your notifications or open it from the Files app.
  2. Allow this once. If Android says your browser can't install apps, tap Settings, turn on Allow from this source, then go back.
  3. Install and open. Tap Install, then Open. ScottPrivacy walks you through the rest.

If Play Protect says the app is from an unknown developer, tap More details › Install anyway. That's normal for apps that don't come from Google Play. Only download ScottPrivacy from this website.

Updates install themselves

Once a day the app checks this website. When there's a new version it asks you, downloads it, checks it, and Android asks you to confirm. You can also tap Settings › Check for updates.

Website version vs. full version

To protect people from fake apps, Google Play Protect blocks any app that can read SMS when it's installed from a website (in Kenya, India, Nigeria, South Africa and other countries). So this download leaves SMS reading out: it has call blocking, the call warning screen, the message checker, security check and cleaner. Automatic scam SMS filtering is in the full version from Palm Store and Google Play.

On a Tecno, Infinix or itel phone?

You'll also find ScottPrivacy in Palm Store, which keeps it updated for you. A Palm Store copy and a copy from this page can't update each other: uninstall the old one first if you switch.
