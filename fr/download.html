Télécharger l'APK

Installez-le en 3 étapes

  1. Ouvrez le fichier. Une fois le téléchargement terminé, touchez-le dans vos notifications ou ouvrez-le depuis l'application Fichiers.
  2. Autorisez une fois. Si Android indique que votre navigateur ne peut pas installer d'applications, touchez Paramètres, activez Autoriser cette source, puis revenez.
  3. Installez et ouvrez. Touchez Installer, puis Ouvrir. ScottPrivacy vous guide pour le reste.

Si Play Protect indique que l'application vient d'un développeur inconnu, touchez Plus de détails › Installer quand même. C'est normal pour les applications qui ne viennent pas de Google Play. Téléchargez ScottPrivacy uniquement depuis ce site.

Sur un ordinateur ?

Scannez ce code avec l'appareil photo de votre téléphone pour ouvrir cette page sur le téléphone, puis touchez Télécharger.

Les mises à jour s'installent toutes seules

Une fois par jour, l'application consulte ce site. S'il y a une nouvelle version, elle vous le propose, la télécharge, la vérifie, et Android vous demande de confirmer. Vous pouvez aussi toucher Paramètres › Rechercher des mises à jour.

Si Play Protect le bloque

Certains téléphones affichent un avertissement Play Protect pour les applications installées depuis un site web. Touchez Plus de détails › Installer quand même. S'il indique que l'application a été bloquée, ouvrez le Play Store, touchez votre photo de profil › Play Protect › l'icône des paramètres, désactivez Analyser les applications avec Play Protect un instant, installez ScottPrivacy, puis réactivez-le.

Vous avez un téléphone Tecno, Infinix ou itel ?

Vous trouverez aussi ScottPrivacy dans Palm Store, qui le met à jour pour vous. Une copie Palm Store et une copie de cette page ne peuvent pas se mettre à jour l'une l'autre : désinstallez d'abord l'ancienne si vous changez.
